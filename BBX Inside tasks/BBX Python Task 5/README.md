# Python Refactoring Tasks

## Overview

This project contains three Python programs created to practice writing clean, readable, and Pythonic code. The tasks focus on refactoring, loops, conditional statements, and user input.

## Project Files

### 1. `refactoring.py`
Demonstrates how to improve Python code by making it more readable, organized, and efficient.

**Concepts covered:**
- Clean code and code readability
- Pythonic coding practices
- Variables and conditional statements

### 2. `guessing_game.py`
A number guessing game in which the user tries to guess a secret number.

**Concepts covered:**
- `while` loops
- `if`, `elif`, and `else` statements
- User input and type conversion
- Comparison operators

### 3. `fizzbuzz.py`
Prints numbers in a sequence and replaces multiples of 3 with `Fizz`, multiples of 5 with `Buzz`, and multiples of both with `FizzBuzz`.

**Concepts covered:**
- `for` loops
- The `range()` function
- The modulo operator (`%`)
- Conditional logic

## Requirements

- Python 3

No additional Python packages are required unless specified in the individual files.
